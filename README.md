# ねるるラジオ

AIによるラジオ番組制作を全自動で実行するAll In Oneキット

## サンプル

このプログラムを使った全自動でのラジオ配信は、以下のURLで行われています

<https://radio.enoki.xyz>

## 仕組み

1. 番組制作用プロンプトがいくつか用意されているので、それらにJartic交通情報やニュースのRSSフィード、放送予定時刻を流し込む。
1. GeminiにAPIを経由してプロンプトを送信し、台本を書いてもらう。
1. 返ってきた台本をVOICEVOX（別でAPIサーバー建ててください）に読み上げさせる。
1. オープニング、エンディング、トーク、BGMをマージして番組として流せるmp3ファイルを出力する。

## 使い方

1. ./env.php.sampleを./env.sampleにコピーして、GeminiのAPIキーを貼り付け
1. ./start-all.sh をcronで毎時50分に設定
